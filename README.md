# Rune

Notes and a calendar for the Mac. Your notes stay on your Mac: no account and
no server.

## Get it

1. Download [Rune.zip](https://github.com/capi-git/Rune/releases/latest/download/Rune.zip).
2. Unzip it and move **Rune** to your Applications folder.
3. Open it.

It needs a Mac with Apple silicon and macOS 14.2 or later. Apple has checked
the app, and it looks for a newer version by itself.

## What you can do

- **Write.** Pages inside pages. Type `/` for headings, to-dos, tables,
  charts, pictures and drawings.
- **Plan.** One calendar. Type an event in words: `Lunch with Sam Friday 1pm`.
- **Meet.** When a call starts, Rune makes a notes page and can write down
  what is said. It never listens by itself.
- **Find.** ⌘K finds any page.
- **Ask an AI, if you want one.** ⌘J asks about a page, or tells the AI to do
  something in Rune ("add a run tomorrow at 7"). One Undo takes it back.

## Add an AI (optional)

Rune works with no AI. To use one, install
[Claude Code](https://claude.com/claude-code) or
[Codex](https://github.com/openai/codex) and sign in one time. Then choose it
in **Settings → AI**. Rune uses your own account.
